# ---- S60 3rd Edition 9.1 (N73): older message numbering ----
# N73 (NokiaDSY SIM start-up, DOS request 806): PN_SIM 0x3B "FA 00" = IMSI-equal query; resp 0x3C
# {service FA, cause 2A = IMSI equal}; without it start-up stays at system state 202
# (docs/devices/nokia-n73-rm132/isi-sim-3b.md)
reply 09 3B 3C FA 2A   # on: n73
# N73 NOKIATSY: product profile read in the older numbering (INFO_PP_READ 0x02/0x03; the N95 uses
# 0x29/0x2A, answered by echoing its sub-blocks). Echo of the one request seen (sub-block 0x47, feature
# 0x01, value 0 = off). Unanswered, it kept DosServer blocked in ETel (custom request 1000019), so
# DosServer never read the SIM channel and start-up stayed at system state 202.
reply 1B 02 03 00 01 47 08 00 01 01 00 00 00   # on: n73
# N73 NOKIATSY SIM requests after the product profile [inferred]: no SIM, so "service, 0x24 = data not
# available" as the N95 accepts for READ_IMSI 0x1D / language 0x1F (response id = request id + 1)
# 09 29 -> 2A is handled dynamically in iscpeer.inl: echo the requested service,
# then status 24. The former constant service 35 made the 5800's ALS query (37) time out.

# ---- 9.3 and later (RAPIDO DSP, 9.3 TSY/SIM start-up): 5730, N79, 5800, N8 ----
# F3 30 -> 31: 58 bytes for every member (the N8 needs seven entries; the 5730/N79/5800 parser reads
# the first four at fixed offsets, so the longer reply is a superset) [V on the N8; smoke-tested on all].
# 5730 (RAPIDO audio): MmfAudioServer's DSP control server asks resource 0xF3 msg 0x30 (header only) and
# waits for 0x31 with 34 bytes {2 unread, A0..A3, B0..B3 as u32}; nothing is validated, zeros = no DSP
# memory to map (docs/devices/nokia-5730-rm465/rapido-audio.md). Without it start-up times out.
# N8: Aamm.dll's 0x31 parser (0x805e8106) reads SEVEN entries [V]: 0..3 as on the 5730 (A at 12..24,
# B at 28..40), then pairs (44,48), (52,56), (60,64): the message must be 68 bytes (58 payload); with
# the 5730's 34 it read offset 52 and !CdspControlServer panicked "IsiMessage: OFFSET Invalid -9".
reply F3 30 31 len=58   # on: 5730 n79 5800 n8
# 5730 playback-time DSP requests, silent (docs/devices/nokia-5730-rm465/rapido-audio.md "Playback
# requests (silent)"): each request is ctl 8 -> 0x32/0x33 -> 0x3B/0x3C; no status is checked, but Aamm
# panics on a sample-rate code outside {2,4,8,..,0x200,0x800,0x1000} (0x33 @14) [V]
reply F3 32 33 00 00 00 02 02 00   # on: 5730 n79 5800 n8
reply F3 3B 3C 00 00 00 00   # on: 5730 n79 5800 n8
# other commands, same pattern [inferred]
reply F3 3D 3E 00 00 00 00   # on: 5730 n79 5800 n8
reply F3 3F 40 00 00   # on: 5730 n79 5800 n8
reply F3 41 42 00 00   # on: 5730 n79 5800 n8
