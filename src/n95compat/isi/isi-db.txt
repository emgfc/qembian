# ISI resource/message names and the fake modem's simple reply table.
#
#   res  ID NAME [evidence]                 resource (ISI resource byte, hex)
#   msg  RES ID NAME [evidence]              message id within a resource (responses: id+1 unless named)
#   reply RES REQ RESP [len=N] BYTES... # comment
#                                            canned reply: data after the message id; len pads with 00
#
# Evidence: verified = seen in N95 code/logs; ref = name from public reference headers (names only,
# no code copied); inferred = guessed from usage. Special-case replies (echoing request data, IMEI,
# light, MTC state machine) stay in src/n95compat/stubs/iscpeer.inl.
# tools/isi.py turns the reply lines into src/n95compat/stubs/isireplies.h (scripts/build-n95compat.sh).
